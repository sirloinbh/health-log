# #107 설정 화면의 금주 목표를 하루 판정과 같은 주 기준으로 보이기

- 이슈: [#107](https://github.com/sirloinbh/health-log/issues/107)
- 브랜치: `feat/107-sober-week-goal`

## 목적

#45에서 금주 목표는 그 주 일요일에 적용되는 목표로 주 전체를 판정한다. 그런데 설정 화면의 "지금 목표"는 오늘 기준이었다. 수요일에 이번 주 금요일부터 금주 6일을 저장하면 하루 기록은 이번 주를 6일로 판정했다. 설정 화면은 옛 목표를 "지금 목표"로 보이고 새 값에는 "(예정)"을 붙였다. PR #103의 2차 리뷰에서 나와 분리한 이슈다.

## 변경 — 2026-11-08

- **API** `backend/src/goals.ts`의 `GET /api/goals`와 `PUT /api/goals/:item` 응답
  - 금주의 `current`를 오늘이 든 주(월~일)의 일요일 기준으로 고른다. 하루 판정(`GET /api/goals/days/:date`)과 같은 기준이다.
  - 칼로리·단백질·수면은 그대로 오늘 기준이다.
  - 응답에 오늘이 든 주 `week: { from, to }`를 더했다.
- **화면** `frontend/src/goal-text.ts`, `frontend/src/goals.tsx`
  - 금주 카드의 설명을 "이번 주(11.02~11.08) 목표: …"로 바꿨다. 다른 카드는 "지금 목표: …" 그대로다(`currentText`).
  - "(예정)"은 항목별 기준일 뒤에 시작하는 변경에만 붙인다(`countsUntil`). 기준일은 금주가 이번 주 일요일, 다른 항목이 오늘이다. 그래서 이번 주 안에서 시작하는 금주 변경은 예정이 아니다.
  - 변경을 지운 뒤 화면에서 바로 계산하는 현재 목표(`withoutChange`)도 같은 기준을 쓴다.

## 변경 — 2026-11-08 (1차 리뷰 반영)

PR #112의 1차 리뷰(작성 문맥과 분리된 읽기 전용 리뷰)는 서버와 화면의 기준이 경계마다 같다고 확인했다. 확인한 경계는 일요일·다음 주 월요일 시작, 오늘이 월요일·일요일인 경우, 이번 주 안에서 끄는 변경이다. 병합을 막을 결함은 없었고 낮음 3개가 나왔다.

- **반영 1** 변경 삭제 확인 문구 "그 날짜부터 바로 앞의 목표로 판정합니다"가 금주에는 맞지 않았다. 금주는 지운 변경이 든 주의 월요일부터 앞 목표로 판정된다. 금주 카드에서는 "삭제하면 그 날짜가 든 주부터 바로 앞의 목표로 판정합니다."로 보인다. #45부터 있던 문구지만 이 PR이 금주를 주 단위로 보이게 바꾸면서 함께 맞췄다.
- **반영 2** 경계 테스트를 보강했다. 이번 주 일요일에 시작하는 변경은 현재 목표가 된다. 이번 주 안에서 목표를 끄면 "이번 주(…) 목표 없음"이 된다(`frontend/src/goal-text.test.ts`).
- **반영 3** 테스트 헬퍼 `goalsOf`가 `today`를 인자로 받으면서 `week`는 고정이라 서버가 만들 수 없는 응답이 될 수 있었다. `today` 인자를 없앴다.
- 테스트: `frontend/src/goals.test.tsx`에 금주와 수면의 삭제 확인 문구 테스트를 더했다.
- 검사: 프론트엔드만 바뀌어 DB 없이 `npm run check`를 실행했고 통과했다.
  - 백엔드: 117개 통과, 99개 건너뜀(DB 통합 테스트). 백엔드 코드는 DB로 221개가 통과한 첫 커밋 뒤 바뀌지 않았다.
  - 프론트엔드: 410개 통과, 2개 건너뜀(다크 전용 조건).
  - `npm run knip`: 통과.

## 2차 리뷰 — 2026-11-08

2차 리뷰(마지막)는 1차 반영이 맞다고 확인했고 고칠 것이 없었다. 새 경계 테스트는 기준을 오늘로 되돌리면 실패한다.

- **참고(고치지 않음)** 같은 주에 금주 목표를 두 번 바꾸면(예: 월요일 5일, 금요일 6일) 앞쪽 변경은 어떤 주도 판정하지 않는다. 그래서 지워도 판정이 바뀌지 않는데, 삭제 문구는 "그 날짜가 든 주부터 바로 앞의 목표로 판정"한다고 말한다. 드문 경우이고 데이터가 잘못될 위험이 없어 그대로 두었다.
