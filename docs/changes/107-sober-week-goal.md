# #107 설정 화면의 금주 목표를 하루 판정과 같은 주 기준으로 보이기

- 이슈: [#107](https://github.com/sirloinbh/health-log/issues/107)
- 브랜치: `feat/107-sober-week-goal`

## 목적

#45에서 금주 목표는 그 주 일요일에 적용되는 목표로 주 전체를 판정한다. 그런데 설정 화면의 "지금 목표"는 오늘 기준이었다. 수요일에 이번 주 금요일부터 금주 6일을 저장하면 하루 기록은 이번 주를 6일로 판정했다. 설정 화면은 옛 목표를 "지금 목표"로 보이고 새 값에는 "(예정)"을 붙였다. PR #103의 2차 리뷰에서 나와 분리한 이슈다.

## 변경 — 2026-11-08

- **API** `backend/src/goals.ts`의 `GET /api/goals`와 `PUT /api/goals/:item` 응답
  - 금주의 `current`를 오늘이 든 주(월~일)의 일요일 기준으로 고른다. 하루 판정(`GET /api/goals/days/:date`)과 같은 기준이다.
  - 칼로리·단백질·수면은 그대로 오늘 기준이다.
  - 응답에 오늘이 든 주 `week: { from, to }`를 더했다.
- **화면** `frontend/src/goal-text.ts`, `frontend/src/goals.tsx`
  - 금주 카드의 설명을 "이번 주(11.02~11.08) 목표: …"로 바꿨다. 다른 카드는 "지금 목표: …" 그대로다(`currentText`).
  - "(예정)"은 항목별 기준일 뒤에 시작하는 변경에만 붙인다(`countsUntil`). 기준일은 금주가 이번 주 일요일, 다른 항목이 오늘이다. 그래서 이번 주 안에서 시작하는 금주 변경은 예정이 아니다.
  - 변경을 지운 뒤 화면에서 바로 계산하는 현재 목표(`withoutChange`)도 같은 기준을 쓴다.
