- 현재 계정은 `health_test`를 만들 수 없지만, `initdb`로 임시 폴더에 PostgreSQL 17을 따로 띄우면 DB 통합 테스트와 브라우저 확인을 실제 SQL로 돌릴 수 있다. 기존 DB는 건드리지 않는다.
- `AGENTS.project.md`는 에이전트 병합을 허용하지만, 자동 모드 권한 검사가 PR #63 병합을 `[Merge Without Review]`로 막았다. 사용자가 직접 병합했다.
