## What we learned

- The ephemeral port range of this PC is 1024-15000, so it can hand out ports that `fetch` rejects (6000, 10080, and so on). That was the cause of the backend tests failing now and then with `bad port`.
- The current account cannot create `health_test`, but if you start PostgreSQL 17 separately in a temporary folder with `initdb`, you can run the DB integration tests and the browser check against real SQL. It does not touch the existing DB.
- `AGENTS.project.md` allows the agent to merge, but the permission check of the auto mode blocked the merge of PR #63 as `[Merge Without Review]`. The user merged it directly.
- The local `main` has no common ancestor with the remote, so `git pull --ff-only` cannot be used. Create new branches from `origin/main`.
