## What we learned

- The detail page of the MFDS DB opens with one URL, so if we store that URL as the source, the values can be compared right away.
- The same food is often listed under a different name in the source (`자장면`, `김밥_참치`). Searching only for exactly matching names misses the analysis records.
- `curl` on Windows can garble Korean in its arguments. That was the reason the public search returned an empty result. It works with Node `fetch`.
- If you use `health_test` in a temporary cluster made with `initdb`, you can run the DB integration tests without touching the existing local DB.
