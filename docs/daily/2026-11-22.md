## What we learned

- Running `npm run check` in several worktrees at once ran out of memory. The lanes now share a lock: create the folder `D:/orca/workspaces/health-log/.check-lock` with `mkdir` (it fails if the folder exists), run the check in the foreground, and remove the folder when it ends. A lock older than 40 minutes is stale.
- Orca holds about 12 terminals. Setup terminals run `npm install` once per worktree, so they count against the limit.
